Linux 使用 MetaCubeX 连接 mihomo 教程

简略说明

mihomo 从 Clash-Meta 演化而来，MetaCubeX 是使用 html 编写的前端 UI。如果您无法成功安装 UI 界面，直接运行命令行加上 web 界面控制面板将是最好的选择。

选择对应 CPU 架构​

  • amd64架构
  • arm64架构

下载下面的软件到同一个文件目录​

下载订阅配置文件​

请先复制订阅链接。

打开操作系统的 应用终端 ，进入软件下载目录，输入下面的命令：

# 下载订阅链接
curl -L -A clashmeta 粘贴上面复制的订阅链接地址 -o config.yaml
# 解压 mihomo
gzip -d mihomo-linux-amd64-v1.19.10.gz
# 重命名
mv mihomo-linux-amd64-v1.19.10 mihomo
# 增加执行权限
chmod +x mihomo
# 解压控制面板
unzip metacubexd-gh-pages.zip
# 重命名
mv metacubexd-gh-pages ui
# 运行
sudo ./mihomo -f config.yaml

控制面板​

打开浏览器，输入下面的 URL 地址：

http://127.0.0.1:9090/ui/

将出现下面的控制界面
